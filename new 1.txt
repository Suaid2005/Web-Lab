## Experiment 1: Event Handling

Aim: To implement JavaScript event handling in a webpage.

### Level 1: Handle Click Events

Concept: The `onclick` event executes a JavaScript function when a user clicks a button.

Program: `event_level1.html`

HTMLWrap linesCopy codePreview

```html

<!DOCTYPE html>
<html>
<head>
    <title>Click Event</title>
</head>
<body>

<h2>JavaScript Click Event</h2>

<button onclick="showMessage()">Click Me</button>

<p id="result"></p>

<script>
function showMessage() {
    document.getElementById("result").innerHTML =
        "Button clicked successfully!";
}
</script>

</body>
</html>
```

Expected Output:

Before clicking:

JavaScript Click Event

Click Me

No message displayed yet.

After clicking:

JavaScript Click Event

Click Me

Button clicked successfully\!

What to write in record:

- Aim
- Program
- Output (before and after clicking)
- Result: Thus, the click event was successfully implemented using JavaScript.

### Level 2: Create Interactive Webpage Using Events

Concept: Use multiple events such as `onclick`, `onmouseover`, and `onmouseout` to make a webpage interactive.

Program: `event_level2.html`

HTMLWrap linesCopy codePreview

```html

<!DOCTYPE html>
<html>
<head>
    <title>Interactive Webpage</title>
</head>
<body>

<h2>Interactive Webpage</h2>

<button onclick="changeText()">
    Click Here
</button>

<h3 id="message">Welcome!</h3>

<p onmouseover="this.style.color='red'"
   onmouseout="this.style.color='black'">
   Move your mouse over this text.
</p>

<script>
function changeText() {
    document.getElementById("message").innerHTML =
        "Hello! Welcome to JavaScript Events.";
}
</script>

</body>
</html>
```

Expected Output:

- Initially, the heading displays `Welcome!`.
- Clicking the button changes the heading to `Hello! Welcome to JavaScript Events.`
- Moving the mouse over the paragraph changes its color to red.
- Moving the mouse away changes its color back to black.

What to write in record:

- Aim
- Program
- Output (show all three event behaviors)
- Result: Thus, an interactive webpage was created successfully using JavaScript events.

## Experiment 2: Form Validation

Aim: To validate user input fields using JavaScript.

### Level 1: Validate Input Fields Using JavaScript

Concept: Check whether the name and email fields are empty before accepting user input.

Program: `form_level1.html`

HTMLWrap linesCopy codePreview

```html

<!DOCTYPE html>
<html>
<head>
    <title>Basic Form Validation</title>
</head>
<body>

<h2>Student Registration</h2>

<form onsubmit="return validateForm()">

    Name:
    <input type="text" id="name">
    <br><br>

    Email:
    <input type="text" id="email">
    <br><br>

    <button type="submit">Submit</button>

</form>

<p id="result"></p>

<script>
function validateForm() {

    let name = document.getElementById("name").value;
    let email = document.getElementById("email").value;

    if (name == "" || email == "") {
        document.getElementById("result").innerHTML =
            "Please fill all fields.";
        return false;
    }

    document.getElementById("result").innerHTML =
        "Form submitted successfully!";

    return false;
}
</script>

</body>
</html>
```

Expected Output:

- If both fields are empty: `Please fill all fields.`
- If both fields are filled: `Form submitted successfully!`

What to write in record:

- Aim
- Program
- Output for empty fields
- Output for filled fields
- Result: Thus, basic form validation was implemented successfully using JavaScript.

### Level 2: Create Complete Form Validation System

Concept: Validate name, email, password, and phone number using JavaScript conditions and regular expressions.

Program: `form_level2.html`

HTMLWrap linesCopy codePreview

```html

<!DOCTYPE html>
<html>
<head>
    <title>Complete Form Validation</title>
</head>
<body>

<h2>Registration Form</h2>

<form onsubmit="return validate()">

    Name:
    <input type="text" id="name">
    <br><br>

    Email:
    <input type="text" id="email">
    <br><br>

    Password:
    <input type="password" id="password">
    <br><br>

    Phone:
    <input type="text" id="phone">
    <br><br>

    <button type="submit">Register</button>

</form>

<p id="result"></p>

<script>
function validate() {

    let name = document.getElementById("name").value;
    let email = document.getElementById("email").value;
    let password = document.getElementById("password").value;
    let phone = document.getElementById("phone").value;

    let emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    let phonePattern = /^[0-9]{10}$/;

    if (name.trim() == "") {
        result.innerHTML = "Enter your name";
    }
    else if (!emailPattern.test(email)) {
        result.innerHTML = "Enter a valid email";
    }
    else if (password.length < 6) {
        result.innerHTML = "Password must contain 6 characters";
    }
    else if (!phonePattern.test(phone)) {
        result.innerHTML = "Enter a valid 10-digit phone number";
    }
    else {
        result.innerHTML = "Registration Successful!";
    }

    return false;
}
</script>

</body>
</html>
```

Expected Output:

| Input condition | Expected message |
| --- | --- |
| Empty name | Enter your name |
| Invalid email | Enter a valid email |
| Password shorter than 6 characters | Password must contain 6 characters |
| Phone not containing 10 digits | Enter a valid 10-digit phone number |
| All fields valid | Registration Successful\! |

Example valid input:

- Name: Rahul
- Email: rahul@gmail.com
- Password: rahul123
- Phone: 9876543210

Registration Successful\!

Expected success output

What to write in record:

- Aim
- Program
- Output for invalid inputs (at least two cases)
- Output for valid inputs
- Result: Thus, a complete form validation system was implemented successfully using JavaScript.

### Level 2: Create Dynamic Pop-up-Based Interaction

Concept: Use `confirm()`, `prompt()`, and `alert()` to create an interactive program based on user responses.

Program: `popup_level2.html`

HTMLWrap linesCopy codePreview

```html

<!DOCTYPE html>
<html>
<head>
    <title>Dynamic Pop-up Interaction</title>
</head>
<body>

<h2>Interactive Pop-up System</h2>

<button onclick="start()">Start Interaction</button>

<p id="result"></p>

<script>

function start() {

    let choice = confirm("Do you want to continue?");

    if (choice) {

        let name = prompt("Enter your name:");

        if (name == null || name.trim() == "") {
            alert("Name not entered!");
            document.getElementById("result").innerHTML =
                "Interaction cancelled.";
        }
        else {
            alert("Welcome " + name + "!");
            document.getElementById("result").innerHTML =
                "Welcome, " + name + "! Have a nice day.";
        }

    }
    else {

        alert("You cancelled the interaction.");

        document.getElementById("result").innerHTML =
            "Interaction cancelled.";

    }
}

</script>

</body>
</html>
```

Expected Output:

When the user clicks Start Interaction:

Case 1: User clicks OK

1. Confirm box appears: `Do you want to continue?`
2. Prompt box appears: `Enter your name:`
3. User enters Rahul.
4. Alert appears: `Welcome Rahul!`
5. Webpage displays: `Welcome, Rahul! Have a nice day.`

Case 2: User clicks Cancel

1. Confirm box appears.
2. User clicks Cancel.
3. Alert appears: `You cancelled the interaction.`
4. Webpage displays: `Interaction cancelled.`

What to write in record:

- Aim
- Program
- Output for OK condition
- Output for Cancel condition
- Result: Thus, dynamic pop-up-based interaction was implemented successfully using JavaScript.
